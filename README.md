### Control
RNSE  
🔘 ↪️ ↩️ = 🔼 🔽

🔘 perss < 1sec = 🆗  
🔘 perss > 1sec = CAN Menu

UP(🔼🔘) < 1sec = 🔼  
UP(🔼🔘) > 1sec = 🎦➕20min

DOWN(🔽🔘) < 1sec = 🔽  
DOWN(🔽🔘) > 1sec = 🎦➖20min

LEFT(|<) < 1sec = ⬅️  
LEFT(|<) > 1sec = 🎦⏮️

RIGHT(>|) < 1sec = ➡️  
RIGHT(>|) > 1sec = 🎦⏭️

RETURN < 1sec = ↩️  
RETURN > 1sec = 🎦⏹️

SETUP < 1sec = ConextMenu | 🎦 OSD  
SETUP > 1sec = CAN Menu
